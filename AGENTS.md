# AGENTS.md

Guidance for AI agents working on the INSAstronaute Unity project.

## Git Workflow

- Work in this repository's existing primary checkout/worktree.
- Do not create an isolated or linked Git worktree.
- Use `main` as the working branch for repository changes.
- Before editing, verify the current branch and working tree, synchronize when
  appropriate, and preserve unrelated local changes.
- After briefly checking a specification for consistency and scope, consider it
  approved by default and continue without waiting for additional confirmation.
